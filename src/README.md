# KlikVPN

Лендинг для сервиса виртуальных серверов **KlikVPN** — виртуальные серверы нового поколения с технологией ИИ-маршрутизации. 14 060 узлов в 166 странах, автоматическая настройка, защищённое соединение.

## 📋 О проекте

Статический лендинг с тёмной темой оформления. На данный момент реализована **только шапка сайта (header)** — логотип, название бренда, подзаголовок, навигационное меню и кнопка CTA.

## 🛠️ Стек технологий

- **HTML5** — семантическая разметка
- **CSS3** — Flexbox, градиенты, transitions, box-shadow
- **Favicon** — PNG-иконка в `/icons/main_website_icon/main_website_icon_2.PNG`
